## Бой

- Атаки по возможности нет.
- Можно произносить заклинание и двигаться.
- Бег: двойное перемещение, единственное действие в раунде.
- Используется восходящий AC, без бросков по таблицам.
- Раунд = 1 минута. Ход = 10 минут.

| Что считаем          | Базовое правило                                                                    |
| -------------------- | ---------------------------------------------------------------------------------- |
| Попадание            | `d20 + итоговый бонус атаки ≥ AC цели`                                             |
| Бонус атаки (AB)     | Берётся из таблицы класса по уровню                                                |
| Сила (STR/СИЛ)       | Модифицирует урон оружием ближнего боя; бонус к попаданию есть только у Воина      |
| Ловкость (DEX/ЛОВ)   | Модифицирует попадание дальнобойным оружием, включая метательное                   |
| Защита (Armor Class) | `AC = 10 + доспех + щит + мод ЛОВ + прочие применимые бонусы`; чем выше, тем лучше |
| Спасбросок           | `d20 + применимые модификаторы ≥ ST персонажа`                                     |
| Ход в бою            | Одно действие и обычное перемещение до или после него; либо только бег             |
| Инициатива           | `d6` за каждую сторону, больший результат действует первым; каждый раунд           |
| Смерть               | При `0 HP` — персонаж без сознания; `0 HP - уровень персонажа` = смерть            |

### Попадание

Бросок атаки: `d20 + итоговый бонус попадания ≥ AC цели`.

| Способ атаки        | Итоговый бонус попадания |
| ------------------- | ------------------------ |
| Оружие ближнего боя | AB (+ мод СИЛ у Воина)   |
| Лук, арбалет, праща | AB + мод ЛОВ             |
| Метательное оружие  | AB + мод ЛОВ             |

- **Магическое оружие** (+1, +2 ...): модификатор добавляется к итоговому бонусу.

### Урон

| Способ атаки        | Расчёт урона          |
| ------------------- | --------------------- |
| Оружие ближнего боя | Урон оружия + мод СИЛ |
| Лук, арбалет, праща | Урон оружия           |
| Метательное оружие  | Урон оружия + мод СИЛ |

- **Мод ЛОВ к урону не прибавляются**, если конкретная способность класса/расы не устанавливает исключение.
- **Магическое оружие** (+1, +2 ...): модификатор добавляется к урону.

### Криты

#### Натуральная 20

- Все классы: полный урон оружием
- Воины: полный урон оружием либо дополнительная атака

#### Натуральная 1

Что-то с оружием: выронили, сорвалась тетива, штраф -1 к броску атаки в следующем раунде

### Дополнительные боевые опции

| Опция                       | Механика                                                                                                                                 |
| --------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| Помощь в бою                | Вместо собственной ближней атаки: +2 к ближним атакам союзника против общего соседнего противника до конца раунда. Максимум 2 помощника. |
| Грязный приём               | Ближняя атака с −4; при успехе цель получает −2 к атакам или AC, по выбору атакующего, до конца раунда                                   |
| Уклонение                   | Отказ от атак и заклинаний ради +2 AC против дальних / ближних атак соответственно                                                       |
| Прикрытие участка стрельбой | Подготовить дальнюю атаку по участку 10 × 10 футов: если враг входит туда до конца раунда, атаковать с +2                                |
| Удар щитом                  | Дополнительная ближняя атака с −4, базовый урон 1d6−1; до конца раунда теряется защита щита                                              |
| Кувырок через противника    | Спасбросок, без атаки в тот же раунд; провал останавливает у ближайшего противника и лишает дальнейшего действия                         |
| Конная атака с разгона      | Полное перемещение верхом и удар копьём: +2 к попаданию, двойной урон                                                                    |
| Копьё против конной атаки   | Без других действий приготовиться встретить разгон: ударить раньше атакующего с +2, при попадании двойной урон                           |

### Ситуационные модификаторы

| Условие                                                    | Эффект                                                      |
| ---------------------------------------------------------- | ----------------------------------------------------------- |
| Дальняя атака в пределах нормальной дальности              | Нет штрафа за дальность                                     |
| Дальше нормальной дальности, но не дальше удвоенной        | −2 к попаданию                                              |
| Дальше удвоенной дальности                                 | Атака этим оружием невозможна                               |
| Стрельба во время ближнего боя или в происходящую схватку  | −2 к попаданию; натуральная 1 означает попадание в союзника |
| Атака невидимой цели, примерное положение которой известно | −4 к попаданию                                              |
| Положение невидимой цели неизвестно                        | Атаковать её нельзя                                         |
| Действие, требующее зрения, в темноте                      | −4 к соответствующему броску d20                            |
| Слабое освещение                                           | Штраф за темноту уменьшается вдвое: до −2                   |

### Лечение

- За день отдыха в безопасном месте восстанавливается 1 HP.
- Перевязка после боя: расход одного набора для лечения (Healer’s Kit), восстановление `d6 HP`. Для одного персонажа
  перевязка возможна только один раз после данного боя.
- Для города: смотри посещение бань, борделей и прочих заведений.
