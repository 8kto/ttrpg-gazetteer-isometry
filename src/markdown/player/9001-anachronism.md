# Анахронизмы

Список фактов и вещей, которые не совпадают по времени, и являются исторически неточными. Некоторые моменты оставлены
для совместимости с приключениями, другие уже закрались ранее в кампанию, и отменить их задним числом мне кажется плохой
идеей.

- Курительные заведения и сами кальяны.
- Чайные заведения.
- Бани.
