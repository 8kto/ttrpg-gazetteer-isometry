# Еда

Основа рациона — хлеб (полба, ячмень) и пиво (густая калорийная ячменная каша с финиками и пряностями).

- **Мясо** — едят только обеспеченные, белок для простонародья — рыба, бобовые, водоплавающая птица
- **Овощи и бобовые** — лук, чеснок, чечевица, нут, бобы фава, огурцы, латук, редис
- **Фрукты** — финики, инжир, гранаты, виноград, дыни
- **Приправы** — соль, мёд (основной подсластитель), тмин, кориандр
- **Масла** — льняное, кунжутное; оливковое — привозное с Леванта

## Чего не существует (анахронизмы)

- Помидоры, картофель, кукуруза, острый перец, тыква, какао — растения Нового Света.
- Цитрусовые и рис — не дошли из Азии.
- Сахар — не дошёл из Индии.
